# 조선 탐정 사무소 2편 · 청심당 독약 사건 — 이미지 의뢰서

필요한 그림: **장소 6장 + 인물 4장 = 모두 10장**
장소 그림은 한 화면짜리이고, 플레이어는 그림 속 물건을 눌러 단서를 찾습니다. 1편 「사라진 봉황 옥비녀」와 같은 방식입니다.

---

## 사건 개요 (개발 메모)

한양 운종가 뒷골목의 한약방 **청심당**. 주인 의원 **허 영감**이 어젯밤 자기 전에 늘 마시던 보약 탕약을 한 모금 마시고 쓰러졌습니다. 맛이 이상해 곧바로 뱉어 낸 덕에 목숨은 건졌지만, 탕약에 독초가 섞여 있었습니다.

| 인물 | 역할 | 겉으로 보이는 혐의 |
| --- | --- | --- |
| 허 도령 | 허 영감의 아들 | 노름빚이 있고, 아버지와 크게 다퉜다 |
| 윤 서방 | 수제자 | 약방을 물려받지 못하게 됐다 |
| 복례 | 탕약 달이는 여종 | 탕약을 직접 달였다 |
| 최 행수 | 약재 납품 상인 | 가짜 인삼을 넣다가 들킬 뻔했다 |

- 증인 2명(그림 속 인물): 허 영감(침소에 누워 있음), 이웃 약초꾼 노인(뒷마당).
- 범인과 단서 사슬은 그림이 나온 뒤 실제 그림에 맞춰 최종 확정합니다. 그래서 아래 표의 물건은 모두 그림에 꼭 들어가야 합니다.

## 쓰는 법

1. GPT 새 대화를 열고 **[0] 공통 스타일**을 먼저 보냅니다.
2. 같은 대화에서 **[1]~[6] 장소**를 한 장씩 보냅니다.
3. 이어서 **[7]~[10] 인물**을 보냅니다.
4. 맨 아래 체크리스트로 확인한 뒤, 10장을 한 폴더에 담아 Claude에게 알려 주세요. (폴더째 첨부하면 빈 파일로 올라오니, 경로를 알려 주거나 파일을 하나씩 첨부해 주세요.)

모든 그림에서 지킬 것

- **글자를 넣지 않는다.** 약장 서랍 이름표, 장부 글씨, 간판도 글자 없이. 이미지 생성기는 한자를 엉터리로 그리는 경우가 많습니다.
- **물건끼리 겹치지 않게, 가장자리에서 잘리지 않게.**
- **단서 물건은 작아도 보이게.** 단, 혼자 반짝이거나 화살표가 붙지 않게.
- **1편 그림과 같은 화풍**으로. 가능하면 1편 그림 한 장을 같이 첨부해 참고하게 하세요.

## 장소 그림 6장

표의 **단서**는 수첩이나 소지품에 들어가는 물건, **일반**은 눌러도 설명만 나오는 물건입니다.

### [1] 약방 (진료실과 약장)

허 영감이 손님을 보고 약을 짓는 방입니다.

| 위치 | 물건 | 구분 | 꼭 보여야 할 것 |
| --- | --- | --- | --- |
| 왼쪽 벽 | 백 칸 약장 | 단서 | 작은 서랍 수십 개, 그중 아래쪽 서랍 하나만 반쯤 열림, 그 서랍 손잡이에 붉은 끈이 묶여 있음 |
| 가운데 왼쪽 | 진료 서안 | 일반 | 맥 짚는 베개, 붓과 벼루 |
| 가운데 | 약 짓는 상 | 단서 | 종이에 싼 약첩 꾸러미 여러 개, 그중 하나가 풀어져 약재가 보임 |
| 가운데 오른쪽 | 약저울 | 단서 | 접시에 검은 가루가 조금 남아 있음 |
| 오른쪽 | 약연(약 가는 배 모양 맷돌) | 단서 | 홈에 검붉은 가루 자국 |

```text
앞 그림과 같은 화풍으로, 가로 3:2 그림. 조선 시대 한약방의 진료실 내부를 정면에서 본 장면. 사람은 없음. 바닥은 장판.
왼쪽부터 오른쪽 순서로 배치해줘.
1. 왼쪽 벽: 작은 서랍이 수십 개 달린 나무 약장. 서랍에 글자는 없음. 아래쪽 서랍 하나만 반쯤 열려 있고, 그 서랍 손잡이에만 붉은 끈이 묶여 있음.
2. 가운데 왼쪽: 낮은 진료 서안. 위에 맥 짚을 때 쓰는 작은 베개, 붓과 벼루.
3. 가운데: 낮은 상 위에 한지로 싸서 끈으로 묶은 약첩 꾸러미 여러 개. 그중 하나는 풀어져 있어 말린 약재 조각이 보임.
4. 가운데 오른쪽: 놋쇠 약저울. 저울 접시에 검은 가루가 조금 남아 있음.
5. 오른쪽 바닥: 배 모양 무쇠 약연과 바퀴 손잡이. 약연 홈에 검붉은 가루 자국이 남아 있음.
붉은 끈, 풀린 약첩, 저울의 가루, 약연의 가루 자국은 작지만 눈에 보이게 그려줘.
```

### [2] 탕약 달이는 곳

복례가 밤마다 허 영감의 보약을 달이는 부엌 한쪽입니다.

| 위치 | 물건 | 구분 | 꼭 보여야 할 것 |
| --- | --- | --- | --- |
| 왼쪽 | 물동이와 바가지 | 일반 | |
| 가운데 왼쪽 | 화로와 약탕관 | 단서 | 불 꺼진 화로 위 손잡이 달린 질그릇 약탕관 |
| 가운데 | 짜는 틀과 베보자기 | 단서 | 약물이 밴 베보자기, 짜고 남은 약재 찌꺼기 |
| 가운데 오른쪽 바닥 | 떨어진 약재 조각 | 단서 | 거무스름하고 울퉁불퉁한 덩이뿌리 조각 하나 |
| 오른쪽 | 탕약 그릇 선반 | 일반 | 빈 사발 몇 개 |

```text
앞 그림과 같은 화풍으로, 가로 3:2 그림. 조선 시대 한약방 부엌 한쪽, 탕약을 달이는 곳을 정면에서 본 장면. 사람은 없음. 바닥은 다진 흙.
왼쪽부터 오른쪽 순서로 배치해줘.
1. 왼쪽: 물이 담긴 질동이와 바가지.
2. 가운데 왼쪽: 불이 꺼진 작은 화로 위에 손잡이가 달린 질그릇 약탕관.
3. 가운데: 나무로 된 약 짜는 틀과 갈색 약물이 밴 베보자기. 옆에 짜고 남은 약재 찌꺼기가 조금 쌓여 있음.
4. 가운데 오른쪽 바닥: 거무스름하고 울퉁불퉁한 덩이뿌리 조각 하나가 떨어져 있음. 다른 약재와 모양이 다름.
5. 오른쪽: 나무 선반 위에 빈 사발 몇 개.
베보자기의 약물 자국과 바닥의 덩이뿌리 조각은 눈에 보이게 그려줘.
```

## 만든 뒤 확인할 것

- [ ] 그림 안에 글자, 한자, 이름표, 낙관이 없다.
- [ ] 표의 물건이 모두 있고, 서로 겹치지 않으며, 가장자리에서 잘리지 않았다.
- [ ] 단서 디테일이 보인다
  - 약방: 붉은 끈 묶인 반쯤 열린 서랍, 풀린 약첩, 저울의 검은 가루, 약연의 가루 자국
  - 달이는 곳: 약물 밴 베보자기, 바닥의 덩이뿌리 조각
  - 침소: 엎어진 사발과 흘린 약물, 빈 약첩 종이
  - 창고: 쏟아진 하얀 뿌리, 장부 사이 쪽지, 자물쇠 긁힌 자국
  - 윤 서방 방: 소매 얼룩, 한지 묶음, 방석 밑 주머니
  - 뒷마당: 보라색 투구꽃과 파헤쳐진 흙, 아궁이 재 속 탄 종이
- [ ] 촛불, 등불, 화로, 아궁이 불이 모두 꺼져 있다.
- [ ] 허 영감(침소)과 약초꾼 노인(뒷마당)이 그림 속에 있다.
- [ ] 10장의 화풍과 색이 1편과 비슷해 보인다.
- [ ] 인물 4명의 얼굴이 서로, 그리고 1편 인물들과도 헷갈리지 않는다.
