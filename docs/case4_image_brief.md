| --- | --- | --- |

### [1] 흑묵당 앞방 (전당포 계산대)

손님이 물건을 맡기는 곳입니다. 점원 아이가 증인으로 그림 속에 있습니다.

| 위치 | 물건 | 구분 | 꼭 보여야 할 것 |
| --- | --- | --- | --- |
| 왼쪽 | 전당물 선반 | 단서 | 맡긴 물건마다 붉은 매듭 꼬리표, 그중 꼬리표만 걸리고 물건이 빠진 빈 자리 하나 |
| 가운데 왼쪽 | 계산대 | 일반 | 주판, 작은 저울 |
| 가운데 | 점원 아이 | 단서(증언) | 계산대 뒤 12살쯤 소년, 솜저고리, 졸린 얼굴 |
| 가운데 오른쪽 | 화로 | 일반 | 숯불 든 놋 화로 |
| 오른쪽 | 출입문 문지방 | 단서 | 문지방 안쪽 마루에 눈 녹은 물 자국이 안쪽으로 이어짐 |

```text
앞 그림과 같은 화풍으로, 가로 3:2 그림. 조선 시대 한양 종로의 전당포 앞방 내부를 정면에서 본 장면. 한겨울. 간판과 종이에 글자 없음.
왼쪽부터 오른쪽 순서로 배치해줘.
1. 왼쪽: 나무 선반에 맡긴 물건들(놋그릇, 비단 보따리, 갓, 작은 함)이 놓여 있고, 물건마다 작은 붉은 매듭 꼬리표가 달려 있음. 그중 한 칸은 꼬리표만 걸려 있고 물건이 비어 있음.
2. 가운데 왼쪽: 낮고 긴 나무 계산대 위에 주판과 작은 저울.
3. 가운데: 계산대 뒤에 앉은 12살쯤 된 점원 소년. 두툼한 솜저고리를 입고 졸린 눈으로 이쪽을 봄.
4. 가운데 오른쪽: 숯불이 은은하게 든 놋쇠 화로.
5. 오른쪽: 바깥에 눈이 보이는 출입문. 문지방 안쪽 마루에 눈 녹은 물 자국이 방 안쪽으로 몇 걸음 이어져 있음.
빈 꼬리표 자리와 눈 녹은 물 자국은 눈에 보이게 그려줘.
```

```text
4. 가운데 오른쪽: 놋 화로. 재 속에 타다 남은 종이 귀퉁이가 조금 보임.
5. 오른쪽: 방문 앞에 털신 한 켤레. 신 밑에 눈 녹은 물이 고여 있음.
젖은 털배자 단, 벽장 틈의 붉은 실, 편지와 칼, 타다 남은 종이는 눈에 보이게 그려줘.
```

## 만든 뒤 확인할 것

- [ ] 그림 안에 글자, 한자, 간판 글씨, 낙관이 없다.
- [ ] 10장이 모두 **한 장씩 따로** 만들어졌다. (합본을 잘라 키운 그림이 아니다)
- [ ] 바깥 장면에 눈이 있고, 실내에 겨울 느낌(화로, 두꺼운 옷)이 있다.
- [ ] 표의 물건이 모두 있고, 서로 겹치지 않으며, 가장자리에서 잘리지 않았다.
- [ ] 단서 디테일이 보인다
  - 앞방: 빈 꼬리표 자리, 눈 녹은 물 자국
  - 금고방: 멀쩡한 자물쇠, 깔끔하게 잘린 붉은 끈, 담뱃재, 잠긴 창 걸쇠
  - 뒷마당: 뒤꿈치가 깊은 발자국, 흐트러지지 않은 담 위 눈, 헛간 사다리
  - 투전판: 붉은 손도장 차용증, 붉은 매듭 엽전 꾸러미
  - 곽 집사 방: 젖은 털배자 단, 벽장 틈 붉은 실, 편지와 칼, 타다 남은 종이
  - 사무소: 증거함 세 칸의 물건
- [ ] 등잔과 촛불이 모두 꺼져 있다.
- [ ] 점원 아이가 [1] 앞방 그림 속에 있다.
- [ ] 인물 4명의 얼굴이 서로, 그리고 1~3편 인물들과도 헷갈리지 않는다.
