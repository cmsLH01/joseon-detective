# 조선 탐정 사무소

조선 시대를 배경으로 한 웹 추리 게임입니다. 현장 그림에서 물건을 찾고, 사람들에게 증거를 보여 주고, 두 단서를 맞춰 추리를 세워 범인을 지목합니다.

주인공은 3년 전 수사를 빼앗기고 포도청을 떠난 이름 없는 "나"입니다. 세 사건 뒤에는 종로 전당포 흑묵당과 그 주인 마 노인이 있고, 사건을 풀 때마다 흑묵당의 흔적이 증거함에 하나씩 쌓입니다. 앞 사건을 풀어야 다음 사건이 열립니다.

- 1편 (봄) 「사라진 봉황 옥비녀」: 참판 댁 마님의 생신 비녀가 자개함에서 사라진 사건
- 2편 (여름) 「청심당 독약 사건」: 한약방 주인의 보약에 독초가 섞인 사건
- 3편 (가을) 「송학서원 시제 유출 사건」: 봉해 둔 과거 시제가 장터 세책점에 돈 사건
- 4편 (겨울) 「흑묵당의 장부」: 마 노인의 장부가 사라진 사건. 마지막 장을 어떻게 할지에 따라 두 갈래 엔딩

## 실행

`index.html` 하나에 그림까지 모두 들어 있습니다. 브라우저로 열면 바로 실행되고, GitHub Pages로도 그대로 동작합니다. 진행 기록은 브라우저에 사건별로 저장됩니다.

## 구조

| 경로 | 내용 |
| --- | --- |
| `index.html` | 게임 본체 (빌드 결과) |
| `src/template2.html` | 화면과 공통 로직, 1편 사건 설정 |
| `src/case1_base.html` | 1편 단서·장소·인물 데이터와 공통 스타일 |
| `src/case2.js` | 2편 단서·장소·인물 데이터 |
| `src/case3.js` | 3편 단서·장소·인물 데이터 |
| `src/case4.js` | 4편 단서·장소·인물 데이터와 두 갈래 엔딩 |
| `src/build.py` | 원본과 그림을 합쳐 `index.html`을 만드는 스크립트 |
| `images/case1`~`case4` | 게임용으로 줄인 그림 (장면 1200×800, 인물 420×420) |
| `docs/` | GPT 그림 의뢰서 |

## 고친 뒤 다시 만들기

```bash
python3 src/build.py
```

그림을 바꿀 때는 `images/` 아래 같은 이름으로 넣고 다시 빌드합니다. 장면 속 누르는 위치는 각 사건 데이터의 `r:[x, y, 너비, 높이]`(1536×1024 기준)로 지정합니다.
